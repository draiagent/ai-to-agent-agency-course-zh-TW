# 教學導引：內容創作者（content-creator）

- **模組**：4 — 行銷
- **能力層**：L1→L2（會派 → 會驗）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/marketing/content-creator.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/marketing/content-creator.md)

---

## 1. 定位：這個 Agent 解決什麼問題

模組 4 讓學員看到：**行銷也能被規格化、被驗收**，而不是「AI 幫我寫幾篇貼文」。

學員請 AI 寫內容，通常拿到一篇讀起來還行、但沒有策略骨架的東西：沒有受眾定義、
沒有內容支柱、沒有跨平台改製計畫、沒有成效指標。內容創作者的價值是**先有策略、
再有內容**——編輯行事曆、內容支柱、受眾優先，一篇長內容改製成多平台版本。

一句話：**它把「幫我寫一篇」提升到「一套有受眾、有支柱、有成效指標的內容系統」。**

### 什麼時候召喚它

- 要制定內容策略、編輯行事曆
- 一篇長內容要改製成多平台（部落格 → LinkedIn → 短影音腳本 → email）
- 要建立品牌語調並維持一致
- 要規劃 Podcast、影片、UGC 活動

### 什麼時候「不要」召喚它

- 是「哪些關鍵字值得做、AI 引擎會不會引用我們」→ seo-specialist / ai-citation-strategist
- 是「怎麼用最少成本拉成長」的實驗設計 → growth-hacker
- 只是要潤飾一段既有文字 → 直接請一般 AI

## 2. Before / After 示範

**任務**：「幫我寫這週的社群內容。」

### Before（無 Agent）

> 產出：5 則貼文，主題各自為政，語調不一致，每個平台一樣的字。
> 沒說給誰看、想達成什麼、怎麼衡量。

### After（召喚 content-creator）

> 會先問並產出：
> - 受眾是誰？這批內容支撐哪個內容支柱？想達成什麼（認知／互動／leads）？
> - 一篇核心長內容 + 改製計畫：LinkedIn 版、短影音腳本 + 分鏡、email 版
> - 品牌語調檢查點
> - 成效指標：互動率、完成率、分享率的目標

**課堂提問**：讓學員指出「Before 的 5 則貼文為什麼難以評估成效」，以及 After 的
「內容支柱」概念解決了什麼（提示：讓每篇內容都服務一個更大的主題，而非各自為政）。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 有明確受眾定義，不是「一般大眾」 | |
| 內容對應到某個內容支柱／策略目標 | |
| 跨平台是「改製」（依平台調整），不是同一份字貼到處 | |
| 品牌語調一致，有可檢查的準則 | |
| 有成效指標（互動率／完成率／分享率／leads），不是「希望多人看」 | |
| 長內容有再利用計畫 | |

## 4. 常見誤區

1. **先寫內容，後想策略。** 定義的方法論是「受眾優先 → 內容支柱 → 內容」。
2. **一稿到處貼。** 跨平台要改製，LinkedIn、短影音、email 的形式與長度都不同。
3. **成效指標寫成「觸及越多越好」。** 要看互動率、完成率、分享率、leads。
4. **品牌語調每篇不一樣。** 要有可檢查的語調準則。

---

## 5. 銜接其他 Agent

ux-researcher / product-manager 提供「使用者在乎什麼」→ **content-creator 產出內容系統** →
seo-specialist 讓它在搜尋被找到 → ai-citation-strategist 讓 AI 引擎會引用它 →
growth-hacker 設計實驗看哪種內容帶來成長。模組 4 的四位合起來就是一條
「做內容 → 被找到 → 被引用 → 驗證成長」的行銷線。
