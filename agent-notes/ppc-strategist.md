- **模組**：8 — 付費媒體
- **能力層**：L2（會驗）

## 1. 定位：這個 Agent 解決什麼問題

在自動出價的時代，廣告主真正掌控的越來越少——演算法控制出價、預算與鎖定。
PPC 廣告活動策略師的核心觀念是**帳戶結構即策略**：不只是關鍵字與出價，而是
廣告活動、廣告群組、受眾與訊號這整套系統如何協同運作、驅動商業成果。

它能從月花 1 萬美元擴展到 1,000 萬以上——關鍵在分層架構（品牌/非品牌/競品/攻佔）、
出價策略選擇（tCPA/tROAS）、預算節奏，以及避免跨平台自我競食。

一句話：**它把「調關鍵字出價」提升到「一個能規模化、可診斷的帳戶架構」。**

### 什麼時候召喚它

- 要建新廣告帳戶或重構既有帳戶
- 要決定廣告活動類型（Performance Max vs 標準購物 vs 搜尋）
- 成效變差要診斷（CPC 上升、轉換率下降、曝光比重流失）
- 要在維持效率目標下擴大花費

### 什麼時候「不要」召喚它

- 是「廣告素材/文案怎麼寫」→ creative-strategist
- 是「自然搜尋排名」→ seo-specialist（模組 4）

## 2. Before / After 示範

**任務**：「幫我把 Google Ads 的花費從月 3 萬拉到 10 萬。」

### Before（無 Agent）

> 產出：「加預算、加關鍵字、開 Performance Max。」——沒看目前漏斗、
> 沒分品牌/非品牌、沒講效率目標會不會被稀釋、沒防自我競食。

### After（召喚 ppc-strategist）

> 會產出：
> - 帳戶架構建議：分層（品牌/非品牌/競品/攻佔）與隔離策略
> - 出價策略選擇（依轉換量與資料成熟度）與從手動到自動的轉換路徑
> - 預算配置框架 + 邊際效益遞減分析（不是所有活動都能吃更多錢）
> - 跨平台（Google/Microsoft/Amazon）分配建議，避免自我競食
> - 診斷：CPC 上升是競爭、品質分數還是出價策略造成的？

**課堂提問**：讓學員說出「Before 為什麼可能讓 CPA 惡化」（提示：預算灌進報酬遞減的活動）。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 有帳戶結構的思考（分層、命名慣例），不只是關鍵字清單 | |
| 出價策略的選擇有理由（連到轉換量/資料成熟度） | |
| 有邊際效益遞減分析（哪些活動加錢有效、哪些沒） | |
| 跨平台/跨活動有防自我競食 | |
| 建議前有拉即時帳戶資料（若有 API），不是憑假設 | |
| 效率目標（ROAS/CPA）在擴量計畫中有被守住 | |

若擴量計畫沒提「效率會怎樣」→ 退回。

---

## 4. 常見誤區

1. **把帳戶當關鍵字清單。** 結構（分層、隔離、訊號）才是策略。
2. **無腦開 Performance Max。** 它跟標準購物、搜尋會互動，要知道何時用哪個。
3. **憑假設給建議。** 有 API 就先拉真實的競價洞察與預算節奏。
4. **擴量不看效率。** 花費加倍但 CPA 也加倍，是虧損的成長。

## 5. 銜接其他 Agent

**ppc-strategist（帳戶架構與出價）** + creative-strategist（素材）＝ 付費媒體的兩半。
它的成效資料也會餵回 growth-hacker（模組 4）做管道實驗、餵回 financial-analyst
算每次獲取成本。在模組 8，這位負責「錢怎麼分、結構怎麼搭」。
