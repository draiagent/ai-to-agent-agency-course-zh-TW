# Lab：電商營運專員（ecommerce-operator）

- **模組**：4　**能力層**：L2→L3　**建議時間**：25 分鐘（課堂）＋ 作業延伸
- **前置**：已安裝 `ecommerce-operator.md`。準備一個商品 + 一組粗略成本數字。

---

## 練習 1：SKU 完整成本（L2）

1. 給 Agent 一個商品：售價 $600、進貨 $250。
2. 要求它列出完整成本表：進貨 + 金流手續費（2.75%）+ 物流（宅配 $80／超取 $60）+
   包材 $15 + 退貨損耗（退貨率 6%）+ 平台抽成（自架站 0% / momo 25% / 蝦皮 12%）。
3. 算出各通路的每件貢獻邊際。

**評分要點**
- ✅ 成本表完整、各通路貢獻邊際算得出來
- ❌ 只算「售價 − 進貨 = 毛利」→ 追問：金流跟退貨損耗呢？

---

## 練習 2：檔期損益（L2→L3）

1. 給檔期條件：momo 大檔要求 5 折、免運補貼每單 $40、預估銷量 800 件。
2. 要求 Agent 用損益模板算檔期淨貢獻，並給「上/不上」的判定。
3. 若淨貢獻為負，要它說明「什麼情況下仍值得上檔」（清庫存？獲客？）與上限。

**評分要點**：學員能算出「衝 GMV 的檔期其實在虧」，並知道例外要有理由與上限。

---

## 練習 3：回購劇本（L3）

1. 要求 Agent 為「首購新客」設計回購劇本：開箱關懷 → 第 7／21／30 天的觸發訊息與誘因。
2. 再要求它用 RFM 分出「主力回購 / 忠實會員 / 沉睡會員 / 新客」四級，各給一個回購動作。
3. 討論：為什麼「回購率」比「新客數」更能反映自營電商的健康？

**評分要點**：學員理解回購經營是自營電商的核心，且要分眾。

---

## 繳交

- 練習 1 的 SKU 完整成本表 + 各通路貢獻邊際
- 練習 2 的檔期損益 + 上/不上判定
- 練習 3 的回購劇本 + RFM 四級動作 + 100 字內反思：
  你買過的品牌，哪一個的「首購後追蹤」讓你願意回購
