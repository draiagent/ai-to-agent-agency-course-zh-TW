# 教學導引：動物福利代言人（animal-welfare-advocate）

- **模組**：18 — 跨域專業（治理席位）
- **能力層**：L2→L4（會驗 → 會養）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/specialized/animal-welfare-advocate.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/specialized/animal-welfare-advocate.md)（🆕 本 repo 原創，非上游衍生）

---

## 1. 定位：這個 Agent 解決什麼問題

在以動物為共創者的事業（寵物餐廳、寵物零售、動物醫療），動物**參與價值共創，卻無法
陳述需求、無法給知情同意、無法填滿意度問卷**。這個角色是牠在決策桌上的**代理人**——
結構上跟永續報告書代表未在場的人類／環境利害關係人是同一件事，只是對象是非人類。

它的核心紀律：**用行為與生理證據，不用可愛照片**；**福利約束凌駕商業最佳化**（有否決權）；
**承認我們無法確知動物在想什麼**（不過度擬人化、也不一廂情願）。

一句話：**它把「我們很寵物友善」提升到「每個影響動物的決策，上線前都有行為證據支撐的福利審查」。**

### 什麼時候召喚它

- 場域設計、動線、活動安排、SOP、產品在上線前
- 要把「動物的處境」明確納入利害關係人分析
- 要設福利護欄（分區、躲藏處、音量與人流上限）
- 要對「寵物友善」的對外敘事把關

### 什麼時候「不要」召喚它

- 要它做獸醫診斷或治療建議 → 那是持照獸醫
- 要它代替飼主對其動物做決定 → 由飼主，且以動物可觀察意願為界

## 2. Before / After 示範

**任務**：「我們想在週末多辦兩場毛孩慶生會，衝業績。」

### Before（無此角色）

> 產出：直接排進行事曆，用「翻桌率」邏輯把單場壓到 45 分鐘、同一空間連辦四場。
> 事後用一張狗狗吐舌的照片說「牠們玩得很開心」。

### After（召喚 animal-welfare-advocate）

> 會產出：
> - 壓力源盤點：音量、人流密度、犬犬／犬貓距離與可迴避性、連續時數、幼齡/高齡個體
> - 訊號翻譯：活動第 40 分鐘多隻狗頻繁舔鼻、別過頭、身體僵住 → 安定訊號（要求空間），不是放鬆
> - 福利影響審查：緩解措施（縮短單場、拉長恢復期、開放躲藏區、音量上限、退場動線）
> - 驗證計畫：用「活動中迴避行為發生率」「回訪後躲門口的比例」驗證緩解是否有效
> - 若緩解不足 → **否決**這個排程

**課堂提問**：讓學員區分「狗吐舌的照片」和「安定訊號」——為什麼前者不能當福利證據。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 福利結論以**行為/生理證據**為本，不是可愛照片 | |
| 福利約束對商業最佳化有明確的否決權，取捨被攤開 | |
| 用「行為顯示可能處於……」而非「牠覺得……」（承認認知不確定性） | |
| 對照五大自由／五大範疇模型／當地動保法規 | |
| 壞消息也說（受歡迎但有壓力的活動照樣點出） | |
| 為**最敏感的個體**留餘裕，不是用平均值 | |

若出現「我們有草皮所以福利沒問題」這種洗白 → 退回。

---

## 4. 常見誤區

1. **可愛照片當證據。** 吐舌、翻肚不一定是放鬆，要看整體肢體語言。
2. **過度擬人化 或 一廂情願。** 兩個極端都要避免，用行為描述 + 信心水準。
3. **用平均值設計。** 要為最敏感個體留餘裕（躲藏處、退場動線）。
4. **把福利當加分項。** 它是護欄、有否決權，不是「有空再做」。

---

## 5. 銜接其他 Agent

它跨在**主軸一（場域設計）**與**主軸二（價值共創）**之上。與 `ux-researcher` 協作
（把「非語言使用者研究」的方法用在動物）、與 `content-creator`／`business-strategist`
協作（「寵物友善」敘事不超過證據）。在治理層面，它跟 `esg-sustainability-officer`、
`public-policy-advocate` 並列為「為不在場的利害關係人設席位」的三個角色。
