# 課程總覽：從「會用 AI」到「會編派 Agent 團隊」

## 課程目標

學員修畢後能夠：

1. 說出「prompt」與「Agent（角色 + 專業流程 + 交付物）」的差別。
2. 面對一個任務，判斷該召喚哪一種專家 Agent。
3. 驗收 Agent 的產出——不是照單全收，而是能指出缺漏並要求修正。
4. 把 2～4 個 Agent 串成一條有明確交付物的流程。
5. 依專案回饋，微調角色設定並沉澱為團隊可重用的資產。

## 教學法

- **每個 Agent 一個節次**，結構固定：定位 → Before/After 示範 → 動手 Lab → 常見誤區。
- **先驗收、後編排**：模組 1～2 練「會派、會驗」，模組 3 起才進「會編」。
- **教材與工具分離**：Agent 定義檔安裝自姊妹 repo，本 repo 只提供教學腳本與練習。
- **不假設學員會寫程式**：模組 3、5 特意放非工程角色，證明 Agent 化不限於工程。

| 5 | 品質、安全、治理 | security-engineer、test-writer、technical-writer、legal-contract-reviewer | L2→L4 |
| 6 | 選修：中國平台團隊 | douyin-strategist、xiaohongshu 系列、wechat-official-account | L1→L3 |

## 單一節次的建議時間分配（60 分鐘）

| 時間 | 內容 |
|---|---|
| 0–10 | 定位：這個 Agent 解決什麼問題、什麼時候不該用它 |
| 10–25 | Before/After 示範：同一任務，無 Agent vs 有 Agent |
| 25–50 | 動手 Lab（`labs/<slug>-lab.md`） |
| 50–60 | 常見誤區 + 與下一個 Agent 的銜接 |
