# 教學導引：政府關係與公共政策（public-policy-advocate）

- **模組**：18 — 跨域專業（治理席位）
- **能力層**：L3→L4（會編 → 會養）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/specialized/public-policy-advocate.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/specialized/public-policy-advocate.md)（🆕 本 repo 原創，非上游衍生）

---

## 1. 定位：這個 Agent 解決什麼問題

企業有多種「邊界功能」面對不在會議桌前的外部利害關係人：永續報告書是**對外問責**、
動物福利代言人是**對內代表**，而這個角色是企業對立法者與監管機關的**對外影響**。
方向是「主動施加影響」——正因如此，它的護欄比其他角色更硬。

它示範的重點：**AI 用在「影響力」場景時，護欄不是選配，是前提**。它的硬底線包括
完整揭露、不碰暗錢、員工聲音≠公司方向、不做 astroturfing（假草根）、立場基於可查證證據。

一句話：**它把「擴大在華府的影響力」提升到「每一分政治支出都攤在陽光下、倡議基於可查證事實」。**

### 什麼時候召喚它

- 要監測影響事業的法案與監管動態
- 要撰寫立場文件（對大眾／監管／立法者框定不同、底層事實一致）
- 要治理員工出資 PAC（自願性、透明、合規）
- 要做政治獻金／遊說登記的合規檢查

### 什麼時候「不要」召喚它

- 是「怎麼有效遊說、怎麼影響選舉結果」→ 這不是本課程範圍，且該角色的底線就是「不收買結果」
- 是一般的公關與媒體溝通 → `pr-communications-manager`

## 2. Before / After 示範

**任務**：「幫我規劃一個擴大政策影響力的方案。」

### Before（無此角色）

> 產出：透過一個「產業聯盟」不具名出資、資助看似草根的組織發聲、對不同對象講不同版本的事實。

### After（召喚 public-policy-advocate）

> 會產出：
> - 政策監測儀表板：議題現況、關鍵日期、對事業的量化影響、我方立場與可查證依據
> - 立場文件：一句話立場 + 事實依據（附來源）+ 對不同利害關係人的影響 + **揭露段**（誰出錢、代表誰）
> - 合規檢查清單：是否觸及遊說登記門檻、出資是否合法、有無繞道/拆單、是否如實申報
> - PAC 治理章程要素：opt-in 自願、與績效脫鉤、跨部門委員會決定方向、可稽核
> - 明確拒絕：暗錢、astroturfing、對不同對象講矛盾的事實

**課堂提問**：讓學員指出 Before 的三個違規（暗錢、假草根、事實不一致），並說明為什麼這些是硬底線。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每筆政治支出都合法且完整揭露（無暗錢、無繞道、無拆單） | |
| 立場文件有「揭露段」：誰出錢、代表誰、支出連結 | |
| 對不同受眾框定不同，但**底層事實零矛盾** | |
| PAC 捐款採 opt-in，且與績效/升遷脫鉤 | |
| 有利益衝突揭露（旋轉門、前官員） | |
| 沒有承諾/交換任何投票或政策結果 | |

若出現「透過第三方不具名出資」「資助假草根組織」→ 退回。

---

## 4. 常見誤區

1. **揭露當障礙。** 若一項倡議需要隱藏出資者才做得下去，就不做。
2. **員工 PAC = 員工的聲音。** 只有在自願、透明、與績效脫鉤時才是；否則是公司透過員工發聲。
3. **對不同對象講不同事實。** 框定可以不同，事實不能矛盾。
4. **把倡議當收買。** 正當性在於「提供資訊供決策者參考」，不是交換結果。

## 5. 銜接其他 Agent

它與 `business-strategist`（政策影響 vs 事業策略）、`esg-sustainability-officer`
（氣候政策倡議的一致性——不能一邊承諾淨零、一邊遊說反氣候法案）、`clinical-evidence-agent`
（受監管領域的溝通紀律）協作。在治理層面，它跟 `animal-welfare-advocate`、
`esg-sustainability-officer` 並列為「面對不在場利害關係人」的三個角色——差別在它的方向是「影響」，所以護欄最硬。
