# 教學導引：交易策略師（deal-strategist）

- **模組**：6 — 銷售
- **能力層**：L2→L3（會驗 → 會編）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/sales/deal-strategist.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/sales/deal-strategist.md)

---

## 1. 定位：這個 Agent 解決什麼問題

學員（尤其非業務背景）常以為 B2B 銷售靠關係與熱情。交易策略師示範的是**把每筆交易
當策略問題**：用 MEDDPICC 框架逐項評分，找出資格缺口，並判斷「這筆到底贏不贏得了」。

它的名言是：「如果資格缺口沒有及早被辨識，敗局其實已經鎖定，只是你還沒發現。」
它對「一廂情願」（happy ears）零容忍——業務說「客戶很愛這個 demo」，它會問
「他們具體說了什麼？誰說的？承諾了什麼下一步？」

一句話：**它把「感覺這筆有機會」提升到「MEDDPICC 八項都答出來、缺口有補救計畫的交易評估」。**

### 什麼時候召喚它

- 要評估一筆複雜 B2B 交易的健康度
- 預測審查前，要讓「這筆會不會成」站得住腳
- 面對競爭對手，要做競爭定位（贏/纏鬥/輸的區塊）
- 想拆穿業務團隊的「一廂情願」

### 什麼時候「不要」召喚它

- 是「怎麼找到新客戶」的開發問題 → outbound-strategist
- 是「這個市場值不值得進」的策略問題 → business-strategist

## 2. Before / After 示範

**任務**：「幫我看這筆大客戶交易怎麼推進。」

### Before（無 Agent）

> 產出：「多跟窗口聊、寄個案例研究、安排 demo。」——沒問經濟買家是誰、
> 決策流程幾步、文書流程開始了沒、迫切事件是什麼。

### After（召喚 deal-strategist）

> 會產出：
> - MEDDPICC 評分表（每項 5 分制）+ 每項的證據與缺口
> - 交易判定：贏 / 纏鬥 / 輸，以及「若 N 天內補上缺口則可贏」
> - 競爭對戰卡：我們贏/纏鬥/輸的區塊 + 話術 + 地雷問題
> - 下一步行動：Champion 牽線 EB、與採購啟動文書流程…

**課堂提問**：讓學員指出「Before 漏了 MEDDPICC 的哪幾項」，以及「文書流程」
（法務/採購/資安審查）為什麼常是「口頭上贏了」的交易死掉的地方。

---

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| MEDDPICC 八項都有評分**與證據**，不是空著 | |
| 有辨識經濟買家（EB），且說明有沒有門路 | |
| 有量化的痛點（不是「他們需要更好的工具」） | |
| 有迫切事件（compelling event），不是人為期限 | |
| 每個缺口都配一個「具體下一步 + 負責人 + 期限」 | |
| 競爭定位分了贏/纏鬥/輸區塊，輸的區塊是「重新定位」不是「攻擊」 | |

若把「友善的窗口」當成 Champion、或沒有迫切事件 → 這筆有停滯風險，退回。

---

## 4. 常見誤區

1. **把接電話的人當 Champion。** Champion 要有權力、有門路、有個人動機，且經得起「請他做一件難的事」的測試。
2. **忽略文書流程。** 第 11 週才發現有 6 週採購週期，會毀掉這一季。
3. **一廂情願。** 「客戶很滿意」不是資訊；「客戶承諾下週把我們列入評估矩陣」才是。
4. **在輸的區塊攻擊對手。** 要縮小它的重要性，不是對自己的能力說謊。

---

## 5. 銜接其他 Agent

outbound-strategist（找到並約到客戶）→ **deal-strategist（評估並推進這筆交易）**。
交易策略師的產出（缺口 + 行動）也會餵回 product-manager（例如「客戶都要匯出功能，
但這不在藍圖上」）。在模組 6，這位是「把管道裡的交易變成可預測營收」的那一棒。
