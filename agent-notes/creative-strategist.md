# 教學導引：廣告素材策略師（creative-strategist）

- **模組**：8 — 付費媒體
- **能力層**：L2（會驗）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/paid-media/creative-strategist.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/paid-media/creative-strategist.md)

## 1. 定位：這個 Agent 解決什麼問題

ppc-strategist 說：在自動出價環境裡，素材是剩下最大的槓桿。廣告素材策略師就是
負責這個槓桿的人——**寫會轉換的廣告，不只是聽起來好的廣告**。

它把「隨手寫幾句廣告文案」提升到「系統化的素材工程」：RSA 的 15 標題策略
（品牌/好處/功能/CTA/社會證明分類，確保每一種組合都讀得通）、素材疲乏監控、
A/B 測試框架、廣告到到達頁的訊息一致性。每個標題、圖片、影片都是一個要測試的假設。

一句話：**它把「寫廣告文案」提升到「可重複的素材測試科學」。**

### 什麼時候召喚它

- 廣告活動上線要寫 RSA 文案（完整 15 標題組）
- 廣告出現疲乏（CTR 下降），要做素材更新
- 要做 Performance Max 素材群組內容
- 要做競品廣告文案分析與差異化

### 什麼時候「不要」召喚它

- 是「帳戶結構/預算/出價」→ ppc-strategist
- 是「品牌內容策略」→ content-creator（模組 4）

## 2. Before / After 示範

**任務**：「幫我寫幾句 Google 搜尋廣告。」

### Before（無 Agent）

> 產出：3 句聽起來不錯的標題，都在講「我們最好、最便宜」。沒有分類、
> 組合起來語意重複、沒有測試計畫、跟到達頁的訊息對不上。

### After（召喚 creative-strategist）

> 會產出：
> - 15 個標題，分成品牌/好處/功能/CTA/社會證明類別，確保任意組合都通順
> - 平台字元數最佳化（30 字標題、90 字說明）
> - 素材測試計畫：明確假設、勝出/落敗標準、統計顯著性
> - 到達頁訊息一致性檢查（標題延續性、CTA 一致）
> - 疲乏監控：哪些廣告已超過最佳曝光門檻

**課堂提問**：讓學員理解「為什麼 RSA 需要『任意組合都通順』」（提示：Google 會自動組合）。

---

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 標題有分類（品牌/好處/功能/CTA/社會證明），不是 15 句同義句 | |
| 任意標題+說明組合都符合文法與邏輯 | |
| 有素材測試計畫：假設 + 衡量標準 + 統計顯著性 | |
| 廣告文案與到達頁訊息一致（不是各講各的） | |
| 有依平台的字元數最佳化 | |
| 寫新素材前有先看現有廣告成效（疲乏、CTR 趨勢） | |

若 15 個標題其實是同一句話的 15 種說法 → 退回。

---

## 4. 常見誤區

1. **只求「聽起來好」。** 目標是轉換，不是文采。具體勝過聰明（數字、時間範圍、具體成果）。
2. **RSA 標題不管組合。** Google 會自動組標題+說明，每一種都要讀得通。
3. **不看現有成效就重寫。** 動筆前先知道什麼有效、什麼在疲乏。
4. **廣告與到達頁脫節。** 廣告承諾 A、到達頁講 B，轉換率一定差。
