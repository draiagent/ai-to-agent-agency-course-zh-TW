# Lab：資深專案經理（project-manager-senior）

- **模組**：5　**能力層**：L2→L3　**建議時間**：25 分鐘（課堂）＋ 作業延伸
- **前置**：已安裝 `project-manager-senior.md`。準備一份簡短規格（一頁的網站/小工具需求即可）。

---

## 練習 1：忠於規格（L2）

1. 給 project-manager-senior 你的規格，要求它產出任務清單。
2. 逐條檢查：**每個任務都能對應回規格的某一句話嗎？** 有沒有規格沒提的功能溜進來？
3. 把「規格沒提但被加進來」的任務圈出來，退回要求移除。

**評分要點**
- ✅ 每個任務都可回溯到規格章節；無鍍金
- ❌ 出現「順便加個 XX」→ 追問：規格哪一段要求這個？

---

## 練習 2：驗收標準（L2）

1. 挑 3 個任務，要求 Agent 為每個補上 Given/When/Then 驗收標準。
2. 檢查：這些標準**可測試**嗎？還是「應該要能用」這種模糊話？
3. 找一個標準最弱的任務，要求它重寫。

**評分要點**：學員能區分「可驗收的標準」與「願望」。

---

## 練習 3：抓缺漏（L2→L3）

1. 故意在規格裡留一個模糊點（例：「使用者可以聯絡我們」但沒說用什麼方式）。
2. 看 Agent 有沒有把它標成「不清楚的要求」，而不是自己決定做一個表單。
3. 把 Agent 標出的缺漏整理成一份「給客戶確認的問題清單」。

**評分要點**：學員理解「規格不清楚時要問，不要猜」——這是專案經理的核心職責。

---

## 繳交

- 練習 1 的任務清單 + 圈出的鍍金項（若有）
- 練習 2 的 3 個任務 + 驗收標準
- 練習 3 的「給客戶確認的問題清單」+ 100 字內反思：
  你最近一個專案有沒有「做到一半才發現規格沒寫清楚」的情況
