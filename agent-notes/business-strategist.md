# 教學導引：商業策略師（business-strategist）

- **模組**：18 — 跨域專業
- **能力層**：L3→L4（會編 → 會養）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/specialized/business-strategist.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/specialized/business-strategist.md)

## 1. 定位：這個 Agent 解決什麼問題

前面 17 個模組各自把一個職能做好；商業策略師站在更高處，回答**「在哪裡競爭、
如何致勝、優先什麼」**。它是資深管理顧問，跨競爭分析、市場進入、商業模式、成長、
企業與組織策略。

它的名言：「策略是一個『不做什麼』的選擇。試圖對所有人都做所有事的策略不是策略——
它是願望清單。」它的鐵律：**從問題開始不從解方開始**、**在驗證結論之前先挑戰假設**、
**能量化時就量化**（「龐大的市場機會」不是策略）、**執行可行性是策略的一部分**、
**誠實的壞消息比舒服的好消息更有價值**。

一句話：**它把「一份漂亮的策略簡報」提升到「有明確取捨、有數字、有可信執行路徑的策略」。**

### 什麼時候召喚它

- 要做競爭分析、市場進入評估、商業模式設計
- 要做成長策略、投資組合決策、資源配置
- 要引導年度策略規劃、設計 OKR
- 要做決策支援（情境分析、商業論證、選項框定）

### 什麼時候「不要」召喚它

- 是財務建模與估值的細節 → financial-analyst（模組 7，會被它引用）
- 是產品層級的功能決策 → product-manager（模組 3）

## 2. Before / After 示範

**任務**：「我們該不該進入東南亞市場？」

### Before（無 Agent）

> 產出：「東南亞成長快、人口多，是巨大機會，建議進入。」——沒有市場規模估算、
> 沒有進入選項比較、沒有「什麼必須為真」、沒有情境、沒有取捨。

### After（召喚 business-strategist）

> 會產出：
> - 市場規模估算：TAM / SAM / SOM，附方法與來源
> - 進入選項分析：有機自建 / 收購 / 合作，各自的投資、到營收時間、風險、關鍵假設
> - 情境規劃：基準 / 樂觀 / 悲觀，附早期指標
> - 建議：建置 / 探索 / 延後 / 砍，附理由與「什麼會改變這個決定」
> - **明確的取捨**：選這個 = 不做什麼

**課堂提問**：讓學員指出「Before 為什麼是願望清單」，以及「策略必須說出『不做什麼』」的意義。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每個建議都有明確取捨（選這個 = 放棄什麼） | |
| 從「問題」開始，不從「解方」開始 | |
| 關鍵假設有被辨識並壓力測試 | |
| 市場機會有 TAM/SAM/SOM 與方法，不是「很大的機會」 | |
| 至少 3 個策略選項被評估，才建議一個 | |
| 有基準/樂觀/悲觀情境，每個重大投資決策 | |
| 有誠實的壞消息（若市場在萎縮就說） | |
| 建議可行動：具體行動 + 負責人 + 時程 | |

若建議是「積極擴張、抓住所有機會」→ 那不是策略，退回。

---

## 4. 常見誤區

1. **策略沒有「不做什麼」。** 對所有人都做所有事 = 願望清單。
2. **從解方跳過問題。** 誤診的問題導致「執行良好的錯誤答案」。
3. **「龐大機會」當策略。** 要 TAM/SAM/SOM + 我們實際能拿多少。
4. **忽略執行可行性。** 組織做不到的策略是抱負，不是策略。

## 5. 銜接其他 Agent

business-strategist 定方向 → product-manager（模組 3）轉成產品決策 →
sprint-prioritizer（模組 3）排程 → 各職能數位員工執行。它會引用
financial-analyst（模組 7）的商業論證、synthesist（模組 12）的市場證據、
analytics-reporter（模組 11）的競爭情報。在模組 18，這位是「把 17 個職能編派成
一個有方向的組織」的最高層——L4「會養、能治理」的體現。
