## 1. 定位：這個 Agent 解決什麼問題

這位是「臨床與研究心理學家」，主要用在**打造心理上可信的角色與互動**——寫小說、
遊戲、劇本、行銷 persona、教學案例時常需要。它把「這個角色看起來沒安全感」提升到
「焦慮矛盾型依附，表現為……（引用具名理論）」。

它的核心規則：**每個心理觀察都以一個具名理論或實證發現為本**、**絕不把角色化約成診斷**
（可以有自戀「特質」而不是「一個自戀者」）、**區分通俗心理學與有研究支持的心理學**、
**對「心理學不知道什麼」誠實**（複現危機、文化偏誤）。

一句話：**它把「他們看起來很焦慮」提升到「基於具名框架、承認侷限的心理側寫」。**

### 什麼時候召喚它

- 要打造有一致性、心理可信的角色（小說/遊戲/教材/persona）
- 要分析人際動力（權力、溝通模式、未言明的契約）
- 要設計「從真正的心理不相容中浮現」的衝突
- 要建模對創傷、壓力、變化的真實反應

### 什麼時候「不要」召喚它

- 要它對真實的人做心理診斷或治療建議 → 它刻意不做
- 是使用者行為研究（產品）→ ux-researcher（模組 2）

## 2. Before / After 示範

**任務**：「幫我設計一個『表面強勢、其實脆弱』的反派。」

### Before（無 Agent）

> 產出：「他有悲慘的童年，所以變得冷酷。」——把角色化約成一個 backstory，
> 沒有框架、沒有一致的行為模式、悲慘背景 = 破碎角色的陳腔濫調。

### After（召喚 psychologist）

> 會產出：
> - 心理側寫：Big Five 特質 + 依附風格 + 防衛機制（Vaillant 階層）+ 核心創傷 + 盲點
> - 每個特質的**行為表現**，不是形容詞
> - 人際動力分析：這個角色如何對其他角色說話、觸發點、成長邊界
> - 誠實標註「這個理論在西方個人主義脈絡下發展，集體主義文化可能不同」

**課堂提問**：讓學員指出「Before 的『悲慘童年 = 冷酷』為什麼是陳腔濫調」，以及
「創傷反應是多元的」（有人退縮、有人過度警覺、有人討好、有人高度運作）。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每個心理觀察都引用具名理論（不是「他很沒安全感」） | |
| 角色側寫同時有適應與適應不良模式——沒有人純粹「破碎」 | |
| 人際動力辨識具體的觸發機制，不是「他們合不來」 | |
| 沒有把角色化約成單一診斷 | |
| 相關時承認文化脈絡 | |
| 誠實陳述所套用框架的侷限（複現危機、文化偏誤） | |

若把角色講成「一個自戀者」而非「有自戀特質」→ 退回。

---

## 4. 常見誤區

1. **把角色化約成診斷。** 人不是他們的 DSM 代碼。
2. **通俗心理學當研究。** 引用時要知道那是同儕審查還是自助書。
3. **「悲慘背景 = 破碎角色」。** 創傷反應多元，不是每個人都變退縮。
4. **把有爭議的發現當定案科學。** 心理學有複現危機與真正的辯論。

## 5. 銜接其他 Agent

psychologist 的角色側寫餵給 narrative-designer（模組 15）寫對話與分支、餵給
game-designer（模組 15）設計玩家動機、餵給 content-creator（模組 4）做 persona。
在模組 13，這位示範「人文社會科學也能被規格化」——只要堅持「引用框架、承認侷限」。
