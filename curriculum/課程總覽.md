# 課程總覽：從「會用 AI」到「會編派 Agent 團隊」

## 課程目標

學員修畢後能夠：

1. 說出「prompt」與「Agent（角色 + 專業流程 + 交付物）」的差別。
2. 面對一個任務，判斷該召喚哪一種專家 Agent。
3. 驗收 Agent 的產出——不是照單全收，而是能指出缺漏並要求修正。
4. 把 2～4 個 Agent 串成一條有明確交付物的流程。
5. 依專案回饋，微調角色設定並沉澱為團隊可重用的資產。

## 教學法

- **每個數位員工一個節次**，結構固定：定位 → Before/After 示範 → 動手 Lab → 常見誤區。
- **先驗收、後編排**：模組 1 先練「會派、會驗」，後段才進「會編」。
- **教材與工具分離**：Agent 定義檔安裝自姊妹 repo，本 repo 只提供教學腳本與練習。
- **不假設學員會寫程式**：設計、產品、行銷模組特意證明 Agent 化不限於工程。

## 課程範圍

姊妹 repo [`AI-to-Agent-Agency-zh-TW`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW)
收錄 **18 個部門、約 40 位數位員工**的繁體中文定義檔（部門 = 上游 division）。

**本課程教案先做 4 個部門**，其餘 14 個部門的教案分批補：

| 模組 | 部門 | 數位員工 | 能力層（見 `mapping.md`） |
|---|---|---|---|
| 1 | 工程 engineering | backend-architect、frontend-developer、code-reviewer、devops-automator、prompt-engineer、ai-engineer、multi-agent-systems-architect | L1→L3 |
| 2 | 設計 design | ui-designer、ux-researcher | L2 |
| 3 | 產品 product | manager（產品經理）、sprint-prioritizer | L2→L3 |
| 4 | 行銷 marketing | content-creator、growth-hacker、seo-specialist、ai-citation-strategist | L1→L2 |

### 後續分批（教案待補，定義檔已在姊妹 repo）

專案管理、銷售、財務、付費媒體、安全、測試、客戶支援、研究、學術、醫療、
遊戲開發、GIS、空間運算、跨域專業。

## 單一節次的建議時間分配（60 分鐘）

| 時間 | 內容 |
|---|---|
| 0–10 | 定位：這個數位員工解決什麼問題、什麼時候不該用它 |
| 10–25 | Before/After 示範：同一任務，無 Agent vs 有 Agent |
| 25–50 | 動手 Lab（`labs/<slug>-lab.md`） |
| 50–60 | 常見誤區 + 與下一個數位員工的銜接 |
