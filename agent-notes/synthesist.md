# 教學導引：研究綜整師（synthesist）

- **模組**：12 — 研究
- **能力層**：L2（會驗）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/research/synthesist.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/research/synthesist.md)

---

## 1. 定位：這個 Agent 解決什麼問題

學員請 AI「幫我查一下這個主題的研究」通常拿到一段「聽起來很有依據、其實混了
腦補與二手複述」的摘要。研究綜整師的核心規則是：**在複述主張之前，先把它追溯到
一手來源**——一個在十個地方被引用的統計數字，若這十處全都追溯回同一份原始研究，
那也只是一個資料點。

它的名言：「一百個指向同一方向的引用，若全都追溯到同一份研究，那也只是一項證據。」
它把「一堆連結」提升到「一張誠實加權的證據地圖：已充分確立 / 有爭議 / 僅單一研究 / 證據缺口」。

一句話：**它把「我查到很多資料都這樣說」提升到「基於 N 個獨立的一手來源，證據實際支持 X」。**

### 什麼時候召喚它

- 要做文獻回顧、把零散來源整理成結構化評估
- 要判斷一個「大家都這樣說」的說法有沒有獨立證據
- 要評估某主張的證據強度（並誠實說出侷限）
- 要為決策提供「這件事我們知道什麼、不知道什麼」

### 什麼時候「不要」召喚它

- 是自己做的一手使用者研究 → ux-researcher（模組 2）
- 是統計方法/因果推論的嚴謹度 → statistician（模組 13）

## 2. Before / After 示範

**任務**：「幫我查『每天喝咖啡對健康的影響』的研究。」

### Before（無 Agent）

> 產出：「研究顯示每天喝咖啡有益心血管健康、可降低第二型糖尿病風險……」
> 沒說搜了哪些來源、樣本多大、哪些是觀察性、哪些被獨立複現、哪些其實都引用同一份。

### After（召喚 synthesist）

> 會產出：
> - 搜尋策略文件：搜了哪些資料庫、什麼日期範圍、納入/排除標準、結果數
> - 來源評估表：每個來源的類型、證據層級、方法品質、是否獨立、在綜整中的份量
> - 證據綜整地圖：已充分確立的、有爭議的、僅單一研究的、證據缺口
> - 信心水準：校準到證據鏈最弱的一環，附推理

**課堂提問**：讓學員理解「循環引用」——多個看似獨立、但全追溯回一個未經查證主張的來源。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每個被綜整的主張都追溯到一個已分級的一手來源 | |
| 有揭露搜尋邊界（資料庫、日期範圍、排除標準） | |
| 來源依證據份量分級（RCT ≠ 意見部落格，即使結論一致） | |
| 有爭議的發現呈現雙方 + 相對強度，不悄悄選多數 | |
| 有陳述「搜尋過但沒找到的」（證據缺口） | |
| 信心水準不高於「最弱的、被實際使用的來源」所能支持的 | |

若出現「來源份量」那格是空的、或十個來源其實都引用同一份 → 退回。

---

## 4. 常見誤區

1. **來源數量 = 證據強度。** 十個弱的或循環的來源，抵不過一個強的。
2. **新 = 比較好。** 未對照既有發現查證的新來源，不能推翻已被充分複現的舊結果。
3. **沉默暗示已解決。** 對某子問題毫無所獲，本身就是一項發現——要說出缺口存在。
4. **把有爭議當定案。** 領域有辯論時，不要把有爭議的發現當成定案的科學呈現。

---

## 5. 銜接其他 Agent

**synthesist（把外部文獻綜整成證據地圖）** 餵給 product-manager（模組 3）做決策、
餵給 ai-citation-strategist（模組 4）判斷「什麼算可信來源」。它跟 statistician
（模組 13）是研究部門的兩半：一個管「文獻說什麼」，一個管「方法站不站得住」。
