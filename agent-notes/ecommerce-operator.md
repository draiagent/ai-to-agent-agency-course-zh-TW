# 教學導引：電商營運專員（ecommerce-operator）

- **模組**：4 — 行銷
- **能力層**：L2→L3（會驗 → 會編）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/marketing/ecommerce-operator.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/marketing/ecommerce-operator.md)（🆕 本 repo 原創，非上游衍生）

---

## 1. 定位：這個 Agent 解決什麼問題

`content-creator` 做內容、`growth-hacker` 做成長實驗、`ppc-strategist` 做付費導流——
電商營運專員負責把這些**變成實際的訂單與回購**：自架站與本地平台並行操作、會員經營、
商品頁轉換、物流金流、退換貨、促購檔期。

它的核心紀律：**每個 SKU 有完整成本**（含金流手續費、物流、退貨損耗、平台抽成）、
**檔期算實際利潤不追 GMV**、**回購率是核心 KPI**、**一稿多通路要改製不是複製**。

一句話：**它把「跟著平台打骨折衝業績」提升到「每個檔期、每個通路、每個 SKU 都算清楚真實利潤」。**

### 什麼時候召喚它

- 要在自架站與本地平台（momo／蝦皮台灣／PChome／LINE）上架、同步、營運
- 要設計會員分級與回購劇本（EDM／LINE／簡訊）
- 檔期規劃要算損益
- 商品頁轉換率要最佳化、退換貨要合規

### 什麼時候「不要」召喚它

- 跨境／Amazon／中國平台 → 需別的角色（本 repo 不收錄中國平台）
- 品牌內容策略 → `content-creator`
- 付費廣告帳戶架構 → `ppc-strategist`
- 「線下→社群→回購」整體漏斗設計 → `growth-hacker`

## 2. Before / After 示範

**任務**：「momo 邀我們上大檔，5 折 + 免運補貼，衝一波。」

### Before（無此角色）

> 產出：直接答應上檔，因為「排名會衝上去、GMV 好看」。沒算金流手續費、
> momo 抽成、免運補貼、退貨損耗——實際每件貢獻邊際是 −$18。

### After（召喚 ecommerce-operator）

> 會產出：
> - 檔期損益模板：預估銷量 × 每件貢獻邊際（售價 − 進貨 − 金流 − 物流 − 包材 − 退貨損耗 − 平台抽成）− 行銷投入 = 檔期淨貢獻
> - 判定：淨貢獻 −$X → 不上；若為清庫存有明確理由與上限
> - 多通路對照：這款在 momo（衝量）、蝦皮（試單）、自架站（品牌+訂閱）分別怎麼操作、商品頁要改製
> - 會員回購劇本：把這批新客導進第 7／21／30 天的回購觸發

**課堂提問**：讓學員算一次「5 折 + 免運補貼 + 抽成」下的每件貢獻邊際，看衝 GMV 是不是虧損。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每個 SKU 有完整成本（進貨 + 金流 + 物流 + 包材 + 退貨損耗 + 平台抽成） | |
| 每個檔期有損益模板，淨貢獻為正（或有明確理由的例外） | |
| KPI 有第 30／60／90 天回購率與世代留存，不只新客數 | |
| 多通路是「改製」（依平台調整），不是同一份商品頁貼到處 | |
| 七日鑑賞期與退換貨合規；會員個資有告知同意 | |
| 折扣有到期日與理由，不把買家訓練成「不打折不買」 | |

若上檔決策沒算貢獻邊際、只看 GMV → 退回。

---

## 4. 常見誤區

1. **衝 GMV 不看利潤。** 侵蝕利潤的營收成長是補貼出來的量。
2. **一稿貼到所有通路。** momo、蝦皮、自架站的邏輯完全不同。
3. **只看新客。** 自營電商的命脈是回購率與世代留存。
4. **忽略隱形成本。** 金流手續費 2–3%、退貨損耗、免運補貼會吃掉利潤。

## 5. 銜接其他 Agent

`content-creator`（內容）→ `growth-hacker`（漏斗實驗）→ **ecommerce-operator（把流量變訂單與回購）**。
定價與各通路報價跟 `pricing-analyst` 協作；退貨原因回饋給 `product-manager` 與 `content-creator`
（商品頁是否誤導）。在寵物餐廳的四主軸中，這位是**主軸三「電商回購」**與**主軸四「B2C 電商」**
的執行者。
