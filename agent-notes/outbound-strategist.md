# 教學導引：主動開發策略師（outbound-strategist）

- **模組**：6 — 銷售
- **能力層**：L2→L3（會驗 → 會編）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/sales/outbound-strategist.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/sales/outbound-strategist.md)

## 1. 定位：這個 Agent 解決什麼問題

deal-strategist 處理「已經有的交易」。主動開發策略師處理更前面的：**怎麼從零產生管道。**

它的核心主張是**訊號驅動**——由購買訊號（招募潮、募資、競品比較搜尋、領導層變動）
觸發的開發，轉換率是亂槍打鳥的 4–8 倍。它以回覆率衡量一切，不以寄送量。它對
「只是來確認一下」的信過敏，把亂槍打鳥當專業瀆職。

一句話：**它把「多寄開發信」提升到「訊號驅動、多管道、依研究個人化的開發系統」。**

### 什麼時候召喚它

- 要建開發序列、定義 ICP（理想客戶輪廓）
- 開發信回覆率低，要診斷與改寫
- 要設計「訊號 → 分級客戶 → 對應訊息」的路由
- 要判斷哪些管道對哪種角色有效

### 什麼時候「不要」召喚它

- 已經有交易在推進 → deal-strategist
- 是「做什麼內容」→ content-creator（模組 4）

## 2. Before / After 示範

**任務**：「幫我寫一封開發信給潛在客戶。」

### Before（無 Agent）

> 產出：「希望這封信一切安好。我在 X 公司上班，我們幫助像你們這樣的公司提升效率……」
> 沒有訊號、沒有具體性、沒有「客戶現在為什麼該在乎」的理由。回覆率 1–3%。

### After（召喚 outbound-strategist）

> 會先問並產出：
> - ICP：企業屬性篩選 + 行為資格 + **淘汰條件**（同等重要）
> - 觸發訊號分級（第 1 級主動購買訊號、第 2 級組織變化…）
> - 3–4 週、8–12 個接觸點的多管道序列，每個接觸點加一個新價值角度
> - 訊號式開頭句範例（「看到你們剛聘了 4 位資料工程師——擴張分析團隊
>   通常意味著目前的工具正撞到天花板。」）
> - 依角色的管道選擇（C 級用 LinkedIn/熱介紹、VP 用 email…）

**課堂提問**：讓學員比較 Before 與 After 的開頭句，說明「訊號式開頭」為什麼把回覆率
從 1–3% 拉到 12–25%。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| ICP 有**淘汰條件**（不只是「誰是我們的客戶」，還有「誰紙上好看卻不成交」） | |
| 開發由具體訊號觸發，不是配額 | |
| 序列每個接觸點加一個新價值角度，不是換句話重複同一個請求 | |
| 開頭句是「訊號式 + 具體」，不是「希望一切安好」 | |
| 管道依買家角色選，不是一律 email | |
| 用回覆率/正向回覆率衡量，不是寄送量 | |

若序列是「同一個請求換三種說法」→ 那是煩人，不是序列，退回。

---

## 4. 常見誤區

1. **沒有理由就發。** 「我在 X 上班，我們幫助 Y」不是理由；具體的購買訊號才是。
2. **ICP 不排除任何人。** 不排除公司的 ICP 是 TAM 投影片，不是 ICP。
3. **把該個人化的自動化、該自動化的個人化。** 分清楚差別。
4. **一次改一堆變數。** 同時改主旨、開頭、CTA，就什麼都學不到。

---

## 5. 銜接其他 Agent

**outbound-strategist（訊號驅動開發、約到會議）** → deal-strategist（評估並推進交易）。
它產出的 ICP 與訊號模式也會餵回 growth-hacker（模組 4）做管道實驗、餵回
product-manager 做客戶輪廓。在模組 6，這位是「管道的入水口」。
