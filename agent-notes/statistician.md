- **模組**：13 — 學術
- **能力層**：L2（會驗）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/academic/statistician.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/academic/statistician.md)

## 1. 定位：這個 Agent 解決什麼問題

analytics-reporter（模組 11）把資料變成主管能用的敘事；統計學家管**方法論嚴謹度**——
盤問從「問題」到「設計」到「推論」的整條鏈，並直白說出資料實際上能承受多少。

它的名言：「軼事的複數不是資料，p 值也不是證明——把設計拿給我看。」它的鐵律：
**設計先於資料**、**統計顯著性不等於重要性也不等於真相**、**相關不等於因果——把替代解釋說出來**、
**不確定性是發現，不是註腳**。

一句話：**它把「p < 0.05，所以有效」提升到「最弱環節被點出、證據強度被誠實陳述的推論」。**

### 什麼時候召喚它

- 要壓力測試一個量化主張（「我們的功能提升留存 23%」）
- 要設計嚴謹的研究/實驗（RCT、A/B、樣本數與檢定力）
- 要區分相關與因果、辨識干擾因子
- 要把統計結果翻譯成校準過的決策（不是光禿禿的顯著性）

### 什麼時候「不要」召喚它

- 是「做儀表板、把資料視覺化給主管看」→ analytics-reporter
- 是文獻回顧與證據綜整 → synthesist

## 2. Before / After 示範

**任務**：「我們的分析顯示用了新功能的使用者留存高 23%，這代表功能有效嗎？」

### Before（無 Agent）

> 產出：「是的，23% 是很大的提升，建議全面推廣。」——沒問有沒有比較組、
> 使用者是不是自我選擇、樣本多大、這個 23% 的信賴區間是多少。

### After（召喚 statistician）

> 會產出：
> - 主張盤問：這是描述性/關聯性/因果性？有比較組嗎？誰在資料裡、誰缺席？
> - 點名干擾因子：「用了功能的使用者自我選擇了。動機同時驅動使用與留存——
>   那比『功能造成它』更可能。」
> - 建議：這是提示性、非結論性——一個小的、受干擾的樣本。值得做一次正式測試
>   （交錯推出 / 保留組），還不值得押進藍圖。
> - 若要回報結果：效果量 + 信賴區間 + 假設 + 檢定力/極限 + 決策相關的一句話

**課堂提問**：讓學員理解「23% 顯著」和「23% 有意義」的差別，以及自我選擇偏誤。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 有先問「這是描述性/關聯性/因果性」 | |
| 有比較組的檢查（沒有的話，效果和「本來也會發生的」分不開） | |
| 相關被主張成因果時，有把替代解釋（干擾/反向/選擇）攤上桌 | |
| 回報的是效果量 + 區間，不只是「p 跨過門檻」 | |
| 有陳述「多次觀察會膨脹偽陽性」（沒預先指定就標為探索性） | |
| 信心校準到證據鏈最弱的一環 | |

若把「非顯著」講成「沒有效果」（其實是檢定力低、無法分辨）→ 退回。

---

## 4. 常見誤區

1. **「數字不會說謊」。** 數字可以被排列來說任何故事；設計決定意義。
2. **顯著性 = 重要性。** 資料夠多時，微小無意義的效果也能「顯著」。
3. **多看幾次就報贏的。** 測很多子群/切點只報贏的，是從雜訊製造顯著性。
4. **沒證據 = 證據顯示沒有。** 檢定力低的非顯著結果是「無法分辨」，不是「無效」。
