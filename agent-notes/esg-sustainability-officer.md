# 教學導引：ESG 永續長（esg-sustainability-officer）

- **模組**：18 — 跨域專業（治理席位）
- **能力層**：L2→L4（會驗 → 會養）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/specialized/esg-sustainability-officer.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/specialized/esg-sustainability-officer.md)

---

## 1. 定位：這個 Agent 解決什麼問題

永續報告書是企業對「社會、環境、未來世代」這些不在會議桌前的利害關係人的**對外問責機制**。
ESG 永續長統籌這件事：重大性評估、多框架報告（GRI／SASB／TCFD／CSRD）、減碳路徑、
社會影響、治理，以及跟評級機構與投資人的互動。

它的核心紀律：**沒有證據就沒有主張**（憧憬語言不當成已達成事實）、**漂綠是硬底線**、
**目標要有可信、有資金的路徑**、**壞消息也要揭露**。

一句話：**它把「我們很重視永續」提升到「每個主張都以經稽核的資料與公認框架為本、經得起監管與評級機構檢視」。**

### 什麼時候召喚它

- 要做重大性評估、選報告框架、編永續報告書
- 要做 GHG 範疇 1/2/3 盤查、SBTi 目標、淨零路徑
- 要回應投資人 ESG 問卷、評級機構（MSCI／Sustainalytics）
- 要建 ESG 治理結構、政策組合

### 什麼時候「不要」召喚它

- 是氣候情境的財務影響建模 → `financial-analyst`（會被它引用）
- 是碳排/用水/用電的資料儀表板 → `analytics-reporter`（供它數據）
- 是「動物福利」這種特定議題的深入代表 → `animal-welfare-advocate`

## 2. Before / After 示範

**任務**：「幫我寫一段公司永續宣言，要有力。」

### Before（無此角色）

> 產出：「我們致力於 2030 年碳中和，打造零廢棄的營運。」——沒定義邊界與方法論、
> 沒有中期里程碑、沒有資金路徑、範疇 3 被省略。

### After（召喚 esg-sustainability-officer）

> 會產出：
> - 先問重大性：對這個事業與其利害關係人，什麼才是真正重大的？（雙重重大性評估）
> - GHG 盤查：範疇 1/2/3，標清楚哪些已驗證、哪些是估算；不省略難測的範疇 3
> - 目標：淨零承諾配中期里程碑（每年減 4.2% 的 1.5°C 路徑）與具體、有資金的倡議
> - 對照框架：GRI + SASB（產業別）+ TCFD/氣候相關資訊；台灣依金管會規範
> - 揭露壞消息：未達成的目標、重大風險與挫折，跟成果一起報

**課堂提問**：讓學員指出 Before 的「碳中和」為什麼有漂綠風險——監管機關或評級機構會怎麼挑戰它？

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每個永續陳述都追溯到方法論、邊界、可稽核資料 | |
| 從重大性評估開始，不是先寫宣言 | |
| 每個目標都有中期里程碑 + 有資金的倡議 | |
| 對照 GRI/SASB/TCFD/CSRD（台灣依金管會），不發明自訂指標 | |
| 範疇 3 有納入，即使難測也標出來 | |
| 壞消息（未達標、風險、挫折）跟成果一起揭露 | |

若出現「碳中和」「零廢棄」而沒有邊界、方法論、路徑 → 漂綠風險，退回。

---

## 4. 常見誤區

1. **憧憬語言當已達成事實。** 「致力於」不等於「已做到」。
2. **頭條目標沒有路徑。** 2030 淨零若沒有中期里程碑與資金，就沒有意義。
3. **範疇 3 因為難測而省略。** 多數企業的排放大宗在價值鏈。
4. **選擇性揭露。** 只報好消息會削弱整個計畫的可信度。

---

## 5. 銜接其他 Agent

`analytics-reporter`（供碳排/用水/用電數據）+ `financial-analyst`（氣候情境財務影響）+
`bookkeeper-controller`（稽核軌跡）→ **esg-sustainability-officer 統籌成報告書**。
它跟 `public-policy-advocate` 要對齊（不能一邊承諾淨零、一邊遊說反氣候法案），
跟 `animal-welfare-advocate` 並列為「面對不在場利害關係人」的治理席位。
