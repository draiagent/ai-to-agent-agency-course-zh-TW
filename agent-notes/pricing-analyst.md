# 教學導引：定價分析師（pricing-analyst）

- **模組**：18 — 跨域專業
- **能力層**：L2（會驗）
- **對應 Agent 定義**：[`AI-to-Agent-Agency-zh-TW` / `agents/specialized/pricing-analyst.md`](https://github.com/draiagent/AI-to-Agent-Agency-zh-TW/blob/main/agents/specialized/pricing-analyst.md)

---

## 1. 定位：這個 Agent 解決什麼問題

定價是少數「改一個數字就直接改獲利」的槓桿，卻常常靠拍腦袋（跟競品打對折、成本加三成）。
定價分析師負責用方法把價格算出來：價值基礎定價 vs 成本加成、貢獻邊際、價格彈性、
分級與套餐設計、B2B 報價、促銷的真實成本。

它的核心紀律：**絕不在真空中定價**（一定放進競品、成本、價值、客群的脈絡）、
**一律把算式秀出來**、**利潤優先保護**、**每個定價建議附 ±20% 敏感度分析**。

一句話：**它把「這個價格感覺可以」提升到「這個價格的貢獻邊際、彈性假設、敏感度區間都寫在紙上」。**

### 什麼時候召喚它

- 新品定價、既有品調價、訂閱分級設計
- B2B / 代工（OEM/ODM）報價，要算量價階梯與底價
- 促銷／檔期要不要做、折扣深度上限
- competitor 調價後要不要跟

### 什麼時候「不要」召喚它

- 是整體商業模式如何攫取價值 → `business-strategist`
- 是單位經濟與現金流 → `financial-analyst`
- 是各通路（momo／蝦皮／自架站）的上架報價執行 → `ecommerce-operator`（會引用它的底價）
- 是 B2B 談判戰術與框架（MEDDPICC 等）→ `deal-strategist`

## 2. Before / After 示範

**任務**：「競品降價 15%，我們要不要跟？」

### Before（無此角色）

> 產出：「跟，不然會流失客戶。」——沒算跟進後的貢獻邊際、沒估流失彈性、
> 沒分「哪些客群真的會走」。

### After（召喚 pricing-analyst）

> 會產出：
> - 現況：我方售價、變動成本、每單位貢獻邊際（把算式列出來）
> - 跟進情境：降 15% 後貢獻邊際變成多少？要多賣幾 % 才打平？（損益兩平量變化）
> - 不跟情境：假設流失率 X%，用 ±20% 敏感度跑三個情境（樂觀／基準／悲觀）
> - 分眾：價格敏感客群 vs 價值型客群，是否用分級／加值方案留住後者
> - 建議：跟或不跟 + 條件（例如只對特定方案、設到期日）

**課堂提問**：讓學員算「降 15% 後要多賣多少 % 才打平」，體會降價的量能要求常常不切實際。

## 3. 怎麼帶學員「驗收」它的產出

| 檢核點 | 有 / 無 |
|---|---|
| 每個定價建議都秀出算式（貢獻邊際、損益兩平量） | |
| 有競品／成本／價值／客群四個脈絡，不是孤立一個數字 | |
| 附 ±20% 敏感度分析（至少樂觀／基準／悲觀三情境） | |
| 明確說明彈性假設的來源（歷史資料？類比？猜測要標明） | |
| 促銷有算「真實成本」（毛利侵蝕 + 買家被訓練的長期效果） | |
| 利潤底線有被保護，不是為了成交無限讓價 | |

若建議只有一個價格數字、沒有算式與敏感度 → 退回。

---

## 4. 常見誤區

1. **成本加成當唯一方法。** 忽略顧客感知價值，常常定得太低。
2. **降價的量能假設不切實際。** 降 20% 常要多賣 50%+ 才打平。
3. **敏感度分析省略。** 彈性是假設，不是事實，一定要跑區間。
4. **促銷只看檔期營收。** 沒算長期毛利侵蝕與「不打折不買」的訓練效果。

---

## 5. 銜接其他 Agent

`financial-analyst`（單位經濟）+ `business-strategist`（商業模式的價值攫取）給脈絡 →
**pricing-analyst 產出價格與敏感度** → `ecommerce-operator`（通路報價執行）、
`deal-strategist`（B2B 談判）落地。在寵物餐廳四主軸中，這位負責
**主軸四「B2B OEM/ODM 報價」的量價階梯與底價**，以及 B2C 電商的分級與檔期折扣上限。
