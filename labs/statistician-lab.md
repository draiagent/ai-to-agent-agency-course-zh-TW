# Lab：統計學家（statistician）

- **模組**：13　**能力層**：L2　**建議時間**：25 分鐘（課堂）＋ 作業延伸
- **前置**：已安裝 `statistician.md`。準備一個你手上（或看過）的量化主張。

---

## 練習 1：走一遍盤問鏈（L2）

1. 給 statistician 一個量化主張（例：「導入 X 後，客訴下降 30%」）。
2. 要求它走完整條盤問鏈：問題 → 測量 → 樣本 → 比較 → 分析 → 推論 → 決策。
3. 找出「最弱的一環」——這個主張最站不住的地方在哪？

**評分要點**
- ✅ Agent 點出最弱環節（通常是「沒有比較組」或「自我選擇」）
- ❌ 直接接受「下降 30% 代表 X 有效」→ 追問：同期還有什麼別的變化？

---

## 練習 2：相關 vs 因果（L2）

1. 給一個關聯：「每週用產品 ≥5 次的使用者，續約率高 40%。」
2. 要求 Agent 提出**至少兩個**「同樣能解釋這個關聯」的替代故事（干擾、反向因果、選擇）。
3. 討論：要做什麼設計才能真的分辨「產品使用導致續約」還是「本來就想續約的人用得多」？

**評分要點**：學員能對任何關聯自動反問「還有什麼能解釋它」。

---

## 練習 3：把結果講對（L2）

1. 給一個 A/B 測試結果：變體 B 的轉換率 12.3%、對照 12.0%、p = 0.04、n = 800/組。
2. 要求 statistician 用「效果量 + 信賴區間 + 實務意義 + 決策」的格式回報，而不是「顯著，上線」。
3. 讓學員判斷：這個 0.3 個百分點，值得做嗎？

**評分要點**：學員能區分「統計顯著」與「值得做」，並要求信賴區間。

---

## 繳交

- 練習 1 的盤問鏈 + 最弱環節
- 練習 2 的兩個替代故事 + 能分辨的設計
- 練習 3 的「效果量 + 區間 + 決策」格式回報 + 100 字內反思：
  你團隊最近一個「數據顯示……」的結論，經得起這條盤問鏈嗎
